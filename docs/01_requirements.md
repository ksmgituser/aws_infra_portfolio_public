## 1. ポートフォリオ作成の目的
本ポートフォリオは、以下の技術要素に関する学習およびスキル習得を目的として作成する。

- AWS上におけるコンテナ技術を活用したアプリケーション基盤の構築  
- Terraformを用いた Infrastructure as Code（IaC）の実践  
- GitHub Actionsを活用した CI/CD 基盤の構築  

なお、本ポートフォリオでは、アプリケーション機能そのものよりも、  クラウドインフラおよび運用設計に重点を置く。

## 4. 非機能要件
### 4.1 性能要件
本システムは、100名規模の企業のIT部門従業員のみを利用対象とすることを想定する。  
想定アクセス数は以下の通りとする。

- 通常時：5台（同時接続3〜5程度）
- ピーク時：10台（同時接続10程度）

### 4.2 可用性要件
本システムは、ピーク時の処理を単一AZの障害時でも継続できるよう、マルチAZ構成とする。


### 4.3. セキュリティ要件
#### 4.3.1. IAMの方針
- 利用者ごとに最小権限の原則を適用する
- 管理者、開発者、運用者でロールを分ける
- ルートユーザーは日常的に使用せず、MFAを必須とする

#### 4.3.2. アクセス制御の方針
- 不要な通信は遮断し、セキュリティグループで制御する
- アプリケーションやサービスへのアクセスは認証済みユーザーのみに限定する
- データベースへのアクセスは必要最小限のアクセス元に限定する
